# 经验分享提纲：用 Agent 拍一部关于 Agent 的电影

这是制作笔记的公开讲述版提纲，不是已经发布的稿件。账号主线仍是“AI-Agent 进入不同的行业、不同的世界，会碰撞出怎样的现实”。本期的世界是电影制作，同时与片中的软件行业形成对应。

## 推荐标题与中心论点

首选：**我用 AI 拍了一部“程序员被 AI 改变”的电影**

备选：

- 用 Agent 拍一部讲 Agent 的电影，谁才是导演？
- 亚瑟成了程序员之后，我也开始重新理解 AI 创作

中心论点：**当 AI 能生成画面、动作和声音，创作工作会更多地集中到选择、组织、连续性与责任上。** 这次项目提供了一组具体例子，尚不足以代表整个影视行业的变化。

## 可直接展开的开场稿

> 我把亚瑟搬进了一间程序员的办公室。枪换成键盘，帮派换成创业团队，对手是一个永远不会累的 Agent。
>
> 然后，我开始用 AI 制作这部电影。
>
> 它能画出一张很漂亮的脸，但下一张不一定还是同一个人。它能让镜头动起来，但人物不一定更有感情。它能把台词念出来，但你未必相信这是一个写了十五年代码的人。
>
> 为了解决这些问题，我开始选演员、建参考图、挑动作、改声音，再把素材接到一条由代码控制的时间轴里。
>
> 片里的老亚在问，AI 来了，我过去的经验还值什么。做这部片的时候，我也在问：当执行可以交给模型，剩下哪些决定仍然需要我来做？

## 五个值得讲成故事的判断

1. **漂亮的一张图不等于一个连续的世界。** 角色参考、服装、年龄和道具成为生产资料；用团队人数、键盘和三年后的阿迭举例。
2. **视频生成应该服务情节。** 交接笔记本是事件，阿迭听见告别后的反应是情绪；两种动作需要不同的镜头设计。
3. **声音是观众认识人物的另一张脸。** 年轻、鼻音、过老、柔软等反馈，把抽象选角判断变成可比较的声音方案。
4. **效率并不总是删掉停顿。** 七秒出品页恢复的原因，是后续叙事需要带入；把一次被纠正的剪辑决定讲清楚。
5. **自动化需要留下证据。** 付费请求超时不能盲目再发，导出成功不能只看文件存在；把任务 ID、预算和完整解码作为制作责任的一部分。

## 费用与效果怎么说

可以说：

> 后期记录范围内，MiniMax 视频、配音与声音设计按标价估算约 139 元。其中视频素材生成了 150 秒，分成 19 个镜头，再经过裁切、复用和剪辑进入八分多钟的影片。

紧接着说明：**这不包含早期图片生成和人工等成本，价格也不是账户发票。** 不能把它包装成“139 元完成整部电影的全部成本”。

旧稿数据可以这样讲：

> 旧稿有 127 次播放，封面标题的点击表现排名不错，但平均播放进度只有 2 分 16 秒。于是我把改版重点放到听懂故事、开场事件和人物反应上。样本很小，目前这是一组制作判断，还需要新版数据验证。

避免把“超过 84% 同类”说成“84% 点击率”，也不要声称补配音已经让留存上涨。留存效果与制作改动不是同一层证据。

## 画面素材与录屏清单

- 先剪同一场景的旧版/新版对比，时间与音量尽量一致，尤其是事故开场。
- 展示两三张角色不连续的历史图，再展示对应参考图与修复结果。
- 展示 `shots.tsv` 的 `id/aspect/refs/prompt`，强调参考图真实随请求提交。
- 展示一个静态首帧、对应 H3 原素材及成片窗口；关掉原生成声音，播放最终混音。
- 试听老亚与米尔顿的少量方案，统一听感响度，随后回到角色画面。
- 架构图拆成三个步骤讲：故事和参考资产、生成候选、代码组织与验收。
- 只截取验证报告的帧数、时长、完整解码、台词覆盖与预算字段。
- 旧稿数据截图裁掉账户信息、浏览器标签页和无关内容；注明是改版前数据。
- 录屏避开 `.minimax`、第三方密钥和临时下载 URL。

## 与正片的发布关系

正片保留完整情绪节奏，经验分享作为独立稿件与它关联。观众可以先看电影再了解制作，也可以从制作过程进入故事。

正片的置顶评论可关联制作分享；分享的简介关联正片与学习笔记。具体发布与关联操作在正式投稿时完成。

适合结尾留下的问题：

> 当一个 Agent 能替你完成越来越多的步骤，你觉得这个行业里，人的哪一种判断会变得更重要？

这个问题既连接本片的制作，也能延续到账号下一次进入的行业与世界。
