## 投稿标题建议

首选：**我用 AI 拍了程序员版《荒野大镖客》，这效果真有电影味了**

其他两个方向：

- 更强调冲突：**亚瑟 VS Agent！我用 AI 拍出了程序员的正午对决**
- 更强调意外感：**把亚瑟变成程序员，再用 AI 拍成电影，没想到是这个味儿**

片名放在简介首行和封面中。标题突出创作行为与意外效果，保留亚瑟/大镖客的游戏入口。若稿件为制作经验分享而非完整正片，可用：**我用 Agent 拍了一部讲 Agent 的电影，最难的竟然是这些决定**。

## 导出与检查

`scripts/export-learning-artifacts.js` 使用 Playwright、本机 Chrome 和 sharp 导出图片。通过 `ARTIFACT_NODE_MODULES` 可指定这些包所在目录；未设置时尝试使用项目依赖。它只导出本地图片，不执行媒体生成或外部投稿。

检查包括字体加载、图片解码、四张卡片的内容与页脚边界，以及 480×270、480×360 的封面缩略图。`out/learning-cards-v2/layout-checks.json` 保存卡片边界检查结果，四张均无宽高溢出。四张卡片预览及 4:3 封面已逐一目视检查，旧版图片保持原文件。
